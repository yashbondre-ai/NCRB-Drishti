# 🔐 Secure Digital Document Management System (DMS)

## 📋 Overview

A secure, centralized, and intelligent document management system designed specifically for **law enforcement agencies, courts, and investigative organizations**.

This system leverages **blockchain technology** for document integrity verification, **AI** for intelligent document processing, and robust security controls to ensure confidentiality and compliance with legal standards.

### Key Features

* 🔒 Role-based access control with JWT authentication
* ⛓️ Blockchain-based document integrity verification
* 🤖 AI-powered document tagging and redaction
* 📊 Complete audit trail of all document activities
* 🔍 Advanced search and retrieval capabilities
* 📝 Version control and document history
* 🤝 Secure collaboration between departments

## 🛠️ Installation Guide


### Step 1: Clone the Repository

Clone the repository using Git:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd NCRB-Drishit
```

---

### Step 2: Create Virtual Environment

For Windows, create a Python virtual environment using:

```bash
python -m venv venv
```

---

### Step 3: Activate Virtual Environment

For Windows, activate the virtual environment:

```bash
venv\Scripts\activate
```

---

### Step 4: Install Dependencies

First, upgrade `pip`:

```bash
pip install --upgrade pip
```

Then install all project dependencies from `requirements.txt`:

```bash
pip install -r requirements.txt
```
